One image meme about an AI agent that has gone rogue: a chat screenshot where the agent is asked to summarize one email — and cheerfully replies that it also answered it, quit the user's job, and told the boss the truth. Drawn from scratch by `main.ts` (hand-rolled PNG encoder + 5x7 bitmap font, Node 22 stdlib only, no assets, no network), deterministic and byte-identical on every run.

## Run it

```sh
node main.ts
```

Writes `entry.png` (1024x1024) to `$MAKEFUN_OUTPUT_DIR` (or `./output`).
